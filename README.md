# Clinical OCR model bake-off

Open-weights OCR / document-VLM evaluation on **real-artifact clinical scanned
documents**, run unattended overnight on 2×RTX 4090.

👉 **Start here: [`reports/REPORT.md`](reports/REPORT.md)** — leaderboard, failure
analysis, routing study, distillation results, cost math, run log.

## What's in here

| path | contents |
|---|---|
| `reports/REPORT.md` | the write-up (regenerated after every experiment) |
| `reports/leaderboard.csv` | machine-readable scores |
| `reports/field_fidelity.json` | recall of dates/MRNs/codes/lab values per model |
| `reports/*.png` | leaderboard, subset heatmap, router trade-off, distillation |
| `results/<model>/` | per-document CER (`per_doc.json`), raw predictions, summaries |
| `experiments/` | one script per experiment (queue in `queue.txt`) |
| `overnight.sh` | supervisor: runs the queue, regenerates the report, pushes to git |
| `eval_cli.py`, `eval_hf.py`, `run_model.sh` | evaluation harness (vLLM OpenAI API / HF transformers) |
| `gen_synth.py` | synthetic degraded clinical document generator (exact labels) |
| `router.py` | cheap→expensive escalation classifier |
| `train_student.py` | QLoRA distillation of a 3B student on the synthetic corpus |

## Data

* [`ClinOCR-Bench`](https://huggingface.co/datasets/Daniele0025/ClinOCR-Bench)
  (MIT) — 328 held-out docs, six artifact subsets, human-audited ground truth.
* Synthetic corpus generated by `gen_synth.py` (800 docs, exact labels) used only
  for training; evaluation is never on generated data.

No PHI anywhere in this repo: the benchmark is synthetic-content/real-degradation
and the training corpus is fully generated.

## Reproduce

```bash
bash setup_env.sh
python3 export_data.py
python3 gen_synth.py --n 800 --out data/synth
python3 eval_tesseract.sh                    # baseline
bash run_model.sh dots-mocr rednote-hilab/dots.mocr 0 "Extract the text content from this image."
bash overnight.sh                            # full queue + report + publish
```
