# Datasets

Two evaluation corpora are used in this benchmark. Both are public or
synthetic; no PHI is involved.

## 1. ClinOCR-Bench — the baseline corpus

- **See / download (canonical source):**
  https://huggingface.co/datasets/Daniele0025/ClinOCR-Bench
- **Licence:** MIT (synthetic clinical content with real-world scan degradations).
- **Size:** 328 test documents across 6 subsets — `normal`, `handwriting`,
  `poor`, `rotated`, `tables`, `mixed`.
- **Exported eval set (doc_id / subset / template / image / ground_truth):**
  [`clinocr_eval.jsonl`](clinocr_eval.jsonl) — every row's `image` points at
  `data/clinocr/images/<subset>/<doc_id>.jpg` once fetched.
- **Fetch script:** `bench/fetch_data.py` (in the `clinical-ocr-bench` repo) or
  `export_data.py` (in this repo).

## 2. medreal — the real-scan corpus

651 pages assembled from four public HuggingFace datasets, then labelled with a
vision LLM (DeepSeek-v4.1-flash) using the same prompt the models are trained
with. It is a generalisation check on real scanners, not a human-audited set.

### Source datasets (see / download)

| source | pages used | link |
|---|---|---|
| noisy-med | 400 | https://huggingface.co/datasets/hmnshudhmn24/noisy-medical-document-images-ocr |
| prescription | 200 | https://huggingface.co/datasets/Technoculture/medical-prescriptions |
| india-hist | 46 | https://huggingface.co/datasets/davanstrien/india-medical-ocr-test |
| medform | 5 | https://huggingface.co/datasets/Ronysalem/medical-forms-dataset |

`india-hist` ships an independent ground truth (ALTO text); the others are
labelled by the teacher only.

### Our derived files (in this folder)

- [`medreal_manifest.jsonl`](medreal_manifest.jsonl) — one row per page:
  `{doc_id, source, image, ref_gt}`. `ref_gt` is the source's own label where one
  exists (used only as a cross-check).
- [`medreal_labels.jsonl`](medreal_labels.jsonl) — the training view:
  `{id, image, text, handwriting}` where `text` is the DeepSeek transcript.
- [`medreal_deepseek_labels.jsonl`](medreal_deepseek_labels.jsonl) — raw labeler
  output: `{doc_id, prediction, latency_s, completion_tokens, cost, error}`.

**Reconstructing the images:** stream the source datasets in the order listed
above and take the first N rows per source (N = pages used), saving each to
`data/medreal/images/<source>/<source>_<i:04d>.jpg`. The `doc_id` in the manifest
matches that convention. Script: `build_medreal.py` in this repo.

**Labelling:** `label_openrouter.py` (model `deepseek/deepseek-v4.1-flash`),
~$0.0009/page, 0 errors, 5.1 min for 651 pages.

## Also used (training / generalisation, not a headline corpus)

- **Synthetic training corpus** — generated by `gen_synth.py` (degraded clinical
  templates with exact labels); 800–4800 docs per experiment.
- **OmniDocBench** — 1651 real PDF pages, Apache-2.0 research-only:
  https://huggingface.co/datasets/opendatalab/OmniDocBench
